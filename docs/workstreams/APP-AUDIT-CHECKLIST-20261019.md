Source baseline: Baatiku/Masanawa `3f380b55205d63bac4f637df884592b7b0a8cdcc`.
Delivered APK source: `f8b5db6d39e907fdbd7b56b2be2ede773dd5197d`, build run 39151671982; recovered release `handset-recovered-39151671982`.

Scope: static review of current mobile routes/screens, chat playback, profile/channel links, account exports, wallet capability handling and Worker composition; reconciliation with existing executed handoffs and CI/build evidence. No new physical-device, live-provider, financial or exhaustive security testing was performed for this checklist. This is a first-pass whole-app audit, not proof that every screen or control works. No WhatsApp APK/REA comparison was performed in this audit.

Authority: Chats · Status · Wallet · Calls · Rooms; Chats launches by default; contacts are Masana AI; MSNW is the sole customer-facing wallet credit. Exact configured voices Bodi/Fora must be preserved. Older Talks-first/Twins/MSN guidance must not override current owner decisions.

Labels: **GAP** = directly evidenced limitation; **VERIFY** = implementation exists or is reported, but the named acceptance remains open; **IMPROVE** = recommendation requiring product prioritization. P0 protects core communication, privacy or money; P1 completes important journeys; P2 improves usability. Unchecked boxes are work, not a statement that the entire feature is absent.

- [ ] **T03 · VERIFY — Assistant reply audio.** Play/pause/seek/replay; test a long answer, missing provider transcription and a partial transcript. No cut-off canonical text, stuck playback, unexpected looping or duplicate autoplay.
- [ ] **T04 · VERIFY — Real one-to-one calls.** Microphone capture, audible remote speech, mute, speaker/earpiece/Bluetooth, hang-up and history readback. Keep the call connected for several minutes; reject a UI-only “connected” result without two-way audio.
- [ ] **T05 · VERIFY — Audio ownership and interruptions.** Start a call during note playback, switch apps, lock/unlock, receive an OS interruption and return. Only one microphone/playback owner; no lost capture, overlapping speech or orphan foreground service.
- [ ] **T06 · VERIFY — Incoming calls and groups.** Foreground/background/terminated app, accept/decline, caller cancel, timeout/missed entry, stale notification, 2–4 Masana participants and leave/end cleanup. Source exists; push and native behavior remain separate acceptance.
- [ ] **T07 · VERIFY — Voice identity.** Compare Gwani and Gwana acoustically on the phone. Directory configuration is not proof of the voice actually heard. Preserve exact Bodi/Fora and the liked existing voice; do not silently substitute a provider roster.
- [ ] **T08 · VERIFY — Account isolation.** Sign out/switch accounts during recording, uploads, streaming, search, profile navigation and playback. No old messages, signed media, notification preview or wallet state may appear for the new account.
- [ ] **T09 · VERIFY — Login and recovery.** Email and numeric-password phone paths, expired/revoked session, wrong password, restart, recovery and session revocation. Phone/password login must not imply verified number ownership.
- [ ] **T10 · VERIFY — Private attachments.** Photos, video, documents and imported audio: supported limits, download/reopen, offline retry, revoked access and cross-account denial. Backend private-media tests passed earlier; physical app handling is still open.
