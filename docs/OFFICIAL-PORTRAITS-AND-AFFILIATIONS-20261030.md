# Official portraits and affiliation placement — 30 October 2026

All 62 active officials now have individually matched public photo references in `services/gateway/src/official_portraits.ts`. Every record binds its stable character ID and canonical official name, photo URL, source page, credit, check date and declared Creative Commons licence where one is supplied. Publisher/official-account photos without a CC declaration are labelled attributed source photographs, never falsely called public domain or openly licensed. No fictional likeness, unrelated namesake or ambiguous group photograph is used as a replacement.

The shared avatar previously discarded every network URL for canonical agents. The new path admits only the current reviewed official's portrait metadata from the server; a mismatched character ID, unreviewed cache entry or arbitrary history/feed URL cannot borrow it. Staff-selected profile imagery is preserved. The explicit HTTP schema now carries portrait and party metadata to Flutter. Shared avatars cover directory, profile, chats, feed author and call surfaces.

A fixed public image catalogue is served through `/public/persona-media/:key`. Requests cannot supply source URLs. The loader bounds source hosts, redirects, timeout, bytes and decoded pixels, converts real raster images to metadata-free WebP, shares concurrent reads and caches public bytes in memory and a dedicated public-portrait subdirectory of the existing persistent volume. Cache filenames are fixed reviewed hashes; the public route cannot address other volume files. Atomic writes and full pixel validation on restart preserve good images when a publisher becomes unavailable. Failed sources back off for one minute. Failures retain initials and are observable by asset key; no mock success. Production warms the actual catalogue in the background and emits decoded/failure counts without delaying Wallet/readiness. Sources are never loaded directly by the citizen's app. Cross-origin public image responses permit web rendering.

Country and party belong in a compact wrapping row below the profile identity and AI disclosure, above the primary actions. Nigeria uses its national flag and country name; APC, ADC, NDC and PDP have sourced emblems with their acronym. The party tooltip states the reported affiliation, full name and check date; tapping it opens the dated roster source. A party emblem or national flag never replaces the AI disclaimer or provenance tick, and does not claim endorsement. Photo credits/source/licence and display-crop notice are in the biography detail. Chat/call controls stay uncluttered.
